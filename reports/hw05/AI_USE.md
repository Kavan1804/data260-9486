# AI Use - HW5

**1. What I used an AI assistant for, and what I did myself.**

I used an AI assistant mainly to understand how to extend my HW4 project for HW5 and where to begin with the new requirements. I used it to review the HW5 instructions, understand how the new components related to my HW4 structure, and clarify the purpose of the required features.

I also used AI for help with Markdown documentation, report organization, explanations, and describing my implementation clearly. When I encountered code errors, I used it to understand the error messages and consider possible solutions. It also helped me go through the execution process, understand the terminal outputs, and determine which screenshots were needed for the submission.

I wrote and implemented the project code myself. I ran the migration, servers, tests, and scripts from my own terminal. I tested the API endpoints and React application, used the MCP Inspector, captured the required screenshots, and verified the reported results against the raw output files.

**2. One AI-produced output that was wrong or unsuitable.**

One explanation provided by the AI assistant was not suitable because it initially described some of the HW5 steps too generally and did not fully match the structure of my existing HW4 project. It also suggested commands and testing steps that needed to be adjusted for my local file paths, ports, and project setup.

I did not use those instructions exactly as provided. I compared them with the HW5 requirements and my existing project, modified the steps for my setup, and verified the results by running the commands myself.

**3. How the problem was detected.**

I detected the issue when the suggested instructions did not match my repository structure and when some of the commands produced errors or did not generate the expected output. I compared the instructions with my HW4 files, the HW5 requirements, and the results from my own terminal.

I also checked the API responses, test results, MCP Inspector output, and screenshots to make sure that the implementation and documentation accurately reflected what I had actually completed.

**4. What was changed and why it works now.**

I adjusted the instructions and explanations to match my actual project structure, local environment, ports, file paths, and execution process. I also corrected the documentation so that it described only the steps and results I personally verified.

This works now because I used the AI assistant for guidance, explanations, documentation, and error interpretation, while independently implementing, running, testing, and verifying the project. The final report and screenshots are based on my own executions and confirmed results.
